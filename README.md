A production-ready relational database architecture normalized to **Third Normal Form (3NF)** for enterprise healthcare operations. Includes atomic stored procedures, cascading triggers, execution plan index optimizations, and hospital revenue window function analytics.

---

## 🌟 Key Features

- **Third Normal Form (3NF) Normalization**: Eliminates partial and transitive dependencies across patients, doctors, admissions, medical records, and billing.
- **Cascading Triggers**: Automated real-time room and bed allocation status updates upon patient admission and discharge.
- **Atomic Stored Procedures**: Multi-step transaction safety for patient registration, diagnosis logging, and invoice generation.
- **Complex Analytics & Window Functions**: `RANK()`, `DENSE_RANK()`, `AVG() OVER()`, and cohort patient recovery interval metrics.
